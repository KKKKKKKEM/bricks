# 003：优先通过组合和 BaseNode 扩展

## 决策

节点使用 `BaseNode` 继承层次表达稳定的节点行为；运行器、基础设施和领域能力优先
通过 Action、协议、Hook、EventBus 和组合语义扩展。

## 原因

- 自定义节点只需要实现 `enter()` / `exit()`，Machine 不必增加类型分支。
- 执行器、存储和事件传输可以替换，不把实现写死在核心。
- 领域适配器可以独立演进，不需要把 Spider、Agent 或 LLM 概念引入 engine。
- 避免为未来可能需要的能力提前创建 Manager、Factory 和全能基类。

新增公开对象前，先确认它有独立职责、稳定生命周期或可替换协议；否则优先使用现有
组合点。
